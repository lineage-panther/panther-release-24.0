# Contributing

Bug reports and feature proposals belong in the [Panther ROM issue tracker](https://github.com/lineage-panther/panther-release-24.0/issues/new/choose).

## Where to send changes

- Release documentation and metadata changes can be proposed as pull requests in this repository.
- Manifest and build-source configuration changes belong in [android_manifests](https://github.com/lineage-panther/android_manifests).
- ROM code changes belong in the repository that owns the affected component. Many source projects are currently referenced upstream and are not forks owned by this project. Until a relevant fork is available, open an issue describing the component, repository path, proposed change, and test plan; do not send ROM source patches to this assets-only repository.

Keep pull requests focused and include relevant build or device-test results. Do not upload complete ROM images, proprietary apps, credentials, or personal device data in an issue or pull request. Preserve upstream copyright and license notices.
